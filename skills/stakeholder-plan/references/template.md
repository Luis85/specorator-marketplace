## 4. Decision rights (RACI)

Cover the decisions that will be contested — not every task.

| Decision | Responsible | Accountable (one) | Consulted | Informed |
|---|---|---|---|---|
| Requirement priority | | | | |
| Deliverable acceptance | | | | |
| Change above threshold | | | | |
| Go-live go/no-go | | | | |
| Data-migration cutover | | | | |

Rules: exactly one Accountable per row; Responsible is who does the work; Consulted is a
two-way obligation before deciding; Informed is one-way after.
