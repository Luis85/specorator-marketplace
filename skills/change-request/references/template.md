# Change-control process (set up once, in the charter)

| Element | Definition |
|---|---|
| **Route** | Anyone may raise → PM logs and assesses within … days → authority decides → baselines updated → status report reflects it |
| **Threshold: PM decides** | ≤ €… and ≤ … days and no scope reduction |
| **Threshold: change authority** | ≤ €… , within stage tolerance |
| **Threshold: project board** | above tolerance, any benefit reduction, any must-have removed |
| **Change budget** | amount, held by …, drawn how |
| **Assessment SLA** | … business days from raise to assessed |
| **Emergency route** | who may authorise verbally, and the retrospective documentation required within … hours |
| **Proportionality** | changes under €… and under … hours are handled as work-management, logged but not formally assessed |
| **Supplier variations** | written variation only; unauthorised work is non-chargeable |
