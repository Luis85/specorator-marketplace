# Exception Report — {{project name}}

Use when a tolerance has been breached or is forecast to be. Short and decision-shaped.

| | |
|---|---|
| **Raised by / date** | |
| **Tolerance breached** | dimension, agreed tolerance, current forecast |

1. **Cause** — what happened, factually, and when it became known.
2. **Consequences** — effect on objectives, benefits, other projects, and commitments already made.
3. **Options** — at least two, each with cost, time, scope, risk, and benefit impact, including
   the do-nothing option.
4. **Recommendation** — one, with reasoning.
5. **Decision required** — from whom, by when, and what happens if the date passes.
6. **Lessons already evident** — if any, for the lessons log.
