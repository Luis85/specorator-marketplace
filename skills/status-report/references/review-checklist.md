# Review checklist — status report

✅ pass / ⚠️ weak / ❌ blocking. Check the arithmetic before the prose.

## Fitness

- [ ] One page for the primary audience; detail in annexes.
- [ ] Leads with the answer — status, forecast, and the one thing that matters.
- [ ] Written for a decision, not as an activity diary.
- [ ] Period covered and reporting date stated.

## Baseline discipline

- [ ] Baseline versions named for scope, schedule, and cost.
- [ ] Every variance is against that baseline, not against last period's forecast.
- [ ] Re-baselining, if any, is disclosed with the authority for it — not silently applied.

## Progress

- [ ] Milestones due this period are listed with achieved / missed / re-forecast.
- [ ] Completion evidence is acceptance, not assertion.
- [ ] The percentage-complete rule is stated and objective.
- [ ] No deliverable has been "90% complete" for more than one period without explanation.

## Metrics

- [ ] EVM indices present for predictive streams, and internally consistent (recompute CPI and
      SPI from PV/EV/AC).
- [ ] EV method stated and not "percent complete by judgement".
- [ ] EAC method named; VAC and TCPI consistent with it.
- [ ] SPI not being used as the primary signal in the final 10–15% of the schedule.
- [ ] Flow metrics for adaptive streams use percentiles, not means.
- [ ] Scope growth is visible where the backlog is growing.
- [ ] Hybrid projects reconcile to one overall position, not two competing ones.
- [ ] No vanity metrics (hours worked, tasks closed, documents produced).

## Forecast

- [ ] A forecast completion date and cost are given, not just current status.
- [ ] Confidence stated, or a range given.
- [ ] Change since the last forecast is stated with a reason.
- [ ] The forecast is consistent with the metrics above it.

## Status integrity

- [ ] RAG criteria are published in the report.
- [ ] Status matches the criteria literally — no green with a missed milestone and no recovery plan.
- [ ] Nothing has been amber for several periods without escalation.
- [ ] Bad news is stated plainly in the headline, not buried in section 5.
- [ ] Status per dimension, not one aggregate colour hiding a red.

## Exceptions and decisions

- [ ] Every tolerance breach or forecast breach appears as an exception.
- [ ] Each exception has cause, options with impacts, and a recommendation.
- [ ] Do-nothing appears as an option where it is real.
- [ ] Every decision requested has an owner, a date, and a consequence of delay.
- [ ] Support asked for is specific and actionable.

## Risk and change

- [ ] Top risks only, with movement since last period.
- [ ] New, closed, and escalated items identified.
- [ ] Risks with no movement across several periods are explained.
- [ ] Change requests in flight are listed with their baseline impact.

## Consistency

- [ ] Numbers reconcile across sections (spend, forecast, variance, exception).
- [ ] Milestone dates match the schedule artifact.
- [ ] Risk IDs and severities match the RAID log.
- [ ] Benefits statement is consistent with the business case.

## Common findings, phrased usefully

| Finding | Say it like this |
|---|---|
| Watermelon status | "Overall is green while M3 slipped 4 weeks and no recovery action is named. Under §RAG that is amber at best — restate and add the intervention." |
| Frozen forecast | "The completion date has been 30 November in all six reports while SPI fell to 0.82. Publish the forecast the metrics imply, or explain the recovery that supports the date." |
| Unfalsifiable EAC | "EAC of €1.4m is given with no method. State it as BAC/CPI = €1.62m, or give the bottom-up re-estimate that supports €1.4m." |
| Inconsistent arithmetic | "CPI is shown as 0.98 but EV €820k / AC €910k = 0.90. Correct the index or the inputs." |
| Activity narrative | "§2 lists 14 workshops held. Replace with the deliverables accepted this period and the ones due and missed." |
| Mean cycle time | "Cycle time is reported as a 6.2-day mean; the 85th percentile is 19 days. Report the percentile — commitments are made against the tail." |
| Problem with no options | "§4 states the environment is unavailable and asks for help. Add two options with cost and date impact, and a recommendation." |
